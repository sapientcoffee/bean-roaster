# 🔥 Bean-Roaster

> Product Discovery, Socratic Alignment, and PRD Synthesis Engine for Antigravity SDLC pipelines (Stages 0–2).

## 🚀 Capabilities

- **Stage 0: Discovery & Ideation (`/ideator`)**: Analyzes persona friction, CUJs, and drafts initial data models.
- **Stage 1: Socratic Alignment (`/grill`)**: Conducts an interactive Socratic interview to resolve edge cases and builds `docs/glossary.md` and `docs/adr/`.
- **Stage 2: PRD Synthesis (`write-prd`)**: Assembles production-grade Product Requirements Documents with measurable KPIs.
- **Stage 2.5: Adversarial Red-Teaming (`@red-team-reviewer`)**: Audits PRDs for blind spots and failure modes before human sign-off.

## 📦 Installation

```bash
# Local workspace
./install.sh

# Or global agy install
agy plugin install .
```
